PROJETO: MOTORISTA VALDINO
TIPO: Landing page comercial
DESENVOLVEDOR: Thiago Marques

OBJETIVO
Criar uma página para divulgar os serviços de transporte do Motorista Valdino e facilitar o contato de clientes pelo WhatsApp.

ARQUIVOS PRINCIPAIS
- index.html: estrutura da página
- style.css: aparência e responsividade
- script.js: interações da página
- img/: imagens utilizadas no projeto

TECNOLOGIAS
- HTML5
- CSS3
- JavaScript
- Git e GitHub

ETAPAS DO PROJETO
1. Desenvolver a página.
2. Testar o layout e os botões.
3. Versionar o código no GitHub.
4. Publicar uma versão de demonstração.
5. Preparar a versão final no Netlify.

OBSERVAÇÕES
- Conferir se as imagens carregam corretamente.
- Configurar o número correto do WhatsApp.
- Testar a página em dispositivos móveis.
- Confirmar com o cliente a autorização para publicação do projeto no portfólio.
